# leonxlnx-minimalist-ui-skill

> 그라디언트와 그림자를 지우고, 따뜻한 단색 톤 + serif 타이포 + bento 그리드로 "문서처럼" 정돈된 화면을 만드는 스킬.

## 이 스킬의 역할

AI가 만든 화면이 "화려하긴 한데 소음 같다"고 느껴질 때,
이 스킬은 **편집 디자인의 절제된 언어**로 화면을 다시 잡습니다.

- 따뜻한 단색 배경 + 한 가지 서체 대비 + 흐린 파스텔 포인트만 허용
- bento 그리드로 영역을 나누되, 테두리는 1px 초경량 회색으로만
- 그림자와 그라디언트를 사실상 제거하고, 여백과 타이포로 위계를 잡음

## 누가 쓰면 좋은지

- **SaaS·도구 제품을 만드는 개발자**: Notion·Linear급 "깔끔한 문서" 느낌을 원할 때
- **포트폴리오·블로그를 만드는 프리랜서**: 화려함보다 읽기 편하고 조용한 화면을 원할 때
- **AI로 화면을 계속 생성하는 팀**: "어려w지만 조용한" 품질 기준을 코드에 반영하고 싶을 때
